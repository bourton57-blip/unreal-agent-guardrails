## No third-party code is bundled

This repository contains **no vendored, copied or relicensed third-party
source code**. Every `.ps1`, `.psd1`, `.psm1` and `.json` file in `src/`,
`tests/`, `examples/`, `schemas/` and `docs/` was written for this project.

## No third-party runtime dependencies

The toolkit has **zero external module dependencies**. It relies only on the
.NET base class library available in Windows PowerShell 5.1:

- `ConvertFrom-Json` / `ConvertTo-Json` (JavaScriptSerializer, .NET Framework)
- `Get-FileHash` with `-Algorithm SHA256` (.NET Framework)
- `System.IO.Path`, `System.Text.RegularExpressions`

No NuGet package, PowerShell module, or third-party library is required, so
there is no third-party license to propagate at runtime.

## MCP servers and Unreal plugins are NOT included

The toolkit **does not** bundle, vendor, download or redistribute any MCP
server, Unreal Engine plugin, or engine content. It only *verifies* artifacts
that a user has already obtained and pinned in their own manifest.

If a user pins a third-party artifact, that artifact remains under its own
license. It is the user's responsibility to comply with it. The toolkit
deliberately surfaces a missing license declaration as a warning so this cannot
pass unnoticed.

## Development-time tooling

The test suite uses a hand-written harness in `tests/TestHarness.ps1` rather
than Pester, precisely to avoid a test-framework dependency. Pester is
therefore **not** a dependency of this project.

## Test fixtures

All fixtures under `tests/fixtures/` are synthetic. They were created for this
repository and contain no proprietary, licensed or third-party content. The
binary fixture `example-tool.bin` is a generated byte array of ASCII text, not
a real executable.
